# 단어 릴레이 배틀(가제) 온라인 — 설계

## 목적
보드게임 "태플"의 **규칙만 참고**해, 이름·그래픽·문구·사운드를 전부 새로 만든 독자적인 온라인 웹게임을 만든다. 광고(배너)로 수익을 내는 것이 목표다. 한글/영어 지원, 타이핑으로 단어를 제출해 턴을 넘기는 방식. 친구를 카카오톡으로 초대해 2~4인 실시간 대전을 하고, 혼자 하는 싱글 모드도 제공한다.
(원 제품 페이지는 접근이 막혀 규칙은 일반적인 Tapple 규칙으로 추정함. 실제 규칙과 다르면 사용자가 바로잡는다.)

## 법적 권리 배제 원칙 (필수)
- "태플", "Tapple" 및 비슷한 이름·로고를 쓰지 않는다. 게임 이름은 가제이며 사용자가 최종 결정한다.
- 원작의 카드 디자인, 버튼 모양, 카테고리 카드 문구, 상자 그림, 효과음을 베끼지 않는다. 그래픽·카테고리 문구·사운드는 전부 새로 만든다.
- 원작이나 제작사를 연상시키는 표현(만두게임즈, 한글판 등)을 게임 안과 광고 문구에 쓰지 않는다.
- 사전 단어 목록은 라이선스가 자유로운 것만 쓰고 출처를 기록한다.
- 이것은 법률 자문이 아니다. 출시 전에 사용자가 한 번 확인한다.

## 규칙 (추정 포함)
1. 라운드마다 카테고리가 하나 나온다 (예: 동물, 과일, 직업).
2. 순서대로 돌아가며 그 카테고리에 맞는 단어를 타이핑해 제출한다. 첫 글자는 아직 쓰이지 않은 글자(한글 초성 / 영어 알파벳)여야 한다.
3. 제출이 받아들여지면 그 글자는 잠기고 다음 사람 차례가 된다.
4. 제한 시간 안에 못 내거나, 규칙에 어긋나거나, 이의제기로 무효가 되면 그 라운드에서 탈락한다. 마지막까지 남은 사람이 라운드를 이긴다.
5. 판정 순서: 첫 글자 검사 → 중복 단어 검사 → 사전 검사(사전에 없으면 탈락) → 통과.
6. 이의제기: 통과한 단어에 다른 플레이어가 이의제기 버튼을 누르면 타이머가 멈추고 나머지가 투표한다. 과반이면 단어 무효, 제출자 탈락. (추측)

## 목표
- 한글 / 영어 전환 가능한 완성도 있는 게임
- 방 만들기 → 카카오톡 초대 → 2~4인 모이면 시작하는 실시간 대전
- 싱글 모드 (컴퓨터 상대, 서버 없이 동작)
- 보기 좋은 그래픽, 타이머(제한시간 표시), 좋은 효과음
- 광고 수익화: 방 대기 화면, 라운드 결과 화면, 메인 화면에 배너 자리를 둔다. 게임 진행 중에는 광고를 띄우지 않는다. 광고 업체는 카카오 애드핏을 기본으로 하되 애드센스로 바꿀 수 있게 한다.
- 광고 심사를 통과할 수 있도록 개인정보처리방침, 이용 안내, 문의처 페이지와 게임 설명 글을 갖춘다.

## 하지 않는 것
- 로그인, 랭킹, 결제(인앱 구매), 앱스토어 앱
- 카테고리 의미 검증 (사전 통과 + 이의제기로 대신함)

## 하지 말아야 할 것 (실패 조건)
- 서버가 없으면 대전이 안 되는 구조 (싱글은 서버 없이 되어야 함)
- 입력 판정이 느리거나 사람마다 결과가 다르게 나오는 것 (판정은 서버가 한 번만 한다)

## 만드는 방식 (제 선택, 사용자는 방향만 승인)
- 웹게임 (브라우저, PC/폰 모두). 프레임워크 없이 가볍게 간다.
- 서버: Node.js + WebSocket. 방 코드와 방 상태를 서버가 관리하고 판정은 서버가 한다.
- 카카오톡 초대: 카카오 JavaScript SDK의 공유 기능으로 방 입장 링크를 보낸다. 링크를 열면 그 방에 바로 들어간다.
- 싱글 모드: 브라우저 안에서 컴퓨터 상대가 단어 목록에서 단어를 골라 낸다.
- 사전: 한글/영어 단어 목록 파일을 게임에 넣어서 쓴다. 외부 API는 쓰지 않는다.
- 카테고리: 약 30개(한글/영어), 컴퓨터 상대가 쓸 카테고리별 단어 목록 포함.
- 그래픽은 CSS 애니메이션, 효과음은 우선 코드로 합성하고 나중에 음원 파일로 교체할 수 있게 한다.

## 빌더에게 맡기는 것
- 사전으로 쓸 단어 목록의 출처 (라이선스가 자유로운 한글/영어 목록)
- 화면 디자인 세부, 효과음 종류, 카테고리 목록 구성
- 라운드 수, 점수 방식, 제한 시간 기본값 (예: 10초, 설정에서 변경)
- 호스팅: 무료 호스팅(예: Render)을 기본으로 함

## 사용자가 해야 하는 것
1. 카카오 개발자 가입: developers.kakao.com → 카카오계정으로 로그인 → 개발자 등록
2. 내 애플리케이션 → 애플리케이션 추가 → 앱 이름 입력
3. 앱 설정 > 플랫폼에서 Web을 추가하고 게임 주소 등록 (주소는 호스팅 후 알려드림)
4. 앱 키 중 **JavaScript 키**를 알려줄 것 (비밀번호가 아니라 공개용 키)
