# Play Console 제출 체크리스트

## 계정
- [ ] 개발자 계정 등록 (US$25), 본인 인증
- [ ] 개인 계정이면: 비공개 테스트 12명 이상 x 14일 연속 (조직 계정은 면제)

## 앱 만들기
- [ ] https://www.pwabuilder.com 에 배포 주소 입력 > Android 패키지 생성 (.aab)
- [ ] 패키지 ID 확정, 서명 키 + 비밀번호 백업
- [ ] Play 콘솔 > 앱 무결성에서 "앱 서명 키" SHA-256 복사
- [ ] store/assetlinks.template.json 을 채워 public/.well-known/assetlinks.json 으로 저장 후 배포
- [ ] https://<도메인>/.well-known/assetlinks.json 이 열리는지 확인 (안 열리면 주소창이 보임)

## 스토어 등록 정보
- [ ] store/listing-ko.md, listing-en.md 붙여넣기
- [ ] 아이콘 512x512: public/icon-512.png
- [ ] 그래픽 이미지 1024x500 제작 (필수)
- [ ] 폰 스크린샷 2장 이상 (권장 4~8장, 홈 / 대기실 / 게임 / 결과)

## 선언
- [ ] 개인정보처리방침 URL
- [ ] 콘텐츠 등급 설문 (폭력, 도박 없음)
- [ ] 데이터 보안: 닉네임/방 코드는 서버 메모리에만 임시 보관, 광고 식별자(AdFit), 음성은 앱이 수집 안 함
- [ ] 광고 포함: 예 / 타깃 연령 13세 이상 권장 / 앱 액세스: 로그인 없음

## 출시
- [ ] 내부 테스트 > 비공개 테스트 > 프로덕션 신청
- [ ] 도메인 확정 후 카카오 개발자 콘솔에 도메인 등록, AdFit 광고 단위 신청
