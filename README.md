# 단어 릴레이 배틀 (가제)

카테고리에 맞는 단어를 아직 안 쓴 글자로 시작해 입력하는 턴제 단어 게임. 한글/영어, 혼자 하기, 2~4인 실시간 대전(카카오톡 초대).

## 내 컴퓨터에서 실행

```bash
npm install
npm start
```

http://localhost:3000 을 엽니다. 테스트는 `npm test`.

## 온라인에 올리기 (Render 무료 플랜)

1. 이 폴더를 GitHub 저장소로 올립니다 (`.gitignore`가 `node_modules`와 도구 폴더를 제외합니다).
2. https://render.com 에 가입하고 **New > Blueprint**에서 저장소를 선택하면 `render.yaml`이 자동으로 읽힙니다.
3. 배포가 끝나면 `https://<이름>.onrender.com` 주소가 생깁니다. WebSocket은 별도 설정 없이 `wss://`로 동작합니다.
4. 무료 플랜은 한동안 접속이 없으면 서버가 잠들어서 첫 접속이 30초쯤 느릴 수 있습니다. 대전 중에는 영향이 없습니다.

## 앱으로 설치하기 (크롬)

- 배포 주소(`https://...`)나 `localhost`에서 열면 크롬 주소창 오른쪽에 설치 아이콘이 생기고, 게임 화면 위쪽에도 "앱 설치" 버튼이 나타납니다.
- 휴대폰 크롬: 메뉴(⋮) > "홈 화면에 추가" 또는 "앱 설치". 설치하면 바탕화면/홈 화면 아이콘으로 실행됩니다.
- 설치된 앱은 인터넷이 없어도 혼자 하기와 한 기기로 여럿이를 시작할 수 있습니다(한 번이라도 접속해서 불러온 언어의 단어 목록만). 온라인 대전은 인터넷이 필요합니다.
- 아이콘은 `scripts/make-icons.js`가 만듭니다. 고치려면 `npm i --no-save sharp && node scripts/make-icons.js`를 실행하세요.
- 서비스 워커(`public/sw.js`)는 새로 배포하면 접속할 때 바로 새 파일을 받습니다. 캐시 때문에 옛 화면이 보이면 `CACHE` 이름의 숫자를 올리세요.

## 카카오톡 초대 켜기

1. https://developers.kakao.com 에서 카카오 계정으로 로그인하고 **내 애플리케이션 > 애플리케이션 추가하기**로 앱을 만듭니다.
2. **앱 설정 > 플랫폼 > Web**에 위 배포 주소(`https://<이름>.onrender.com`)를 등록합니다.
3. **앱 키**에서 **JavaScript 키**를 복사해 `public/config.js`의 `kakaoJsKey`에 붙여 넣고 다시 배포합니다.
4. 키가 비어 있으면 카카오 버튼은 숨겨지고 "링크 복사"만 보입니다.

## 광고 달기 (카카오 애드핏)

1. https://adfit.kakao.com 에서 매체(사이트)를 등록하고 심사를 통과한 뒤 광고단위(320x100)를 만듭니다.
2. 광고단위 ID(`DAN-...`)를 `public/config.js`의 `adfitUnitId`에 넣고 다시 배포합니다.
3. 광고는 메인, 대기실, 라운드 결과 화면에만 나오고 게임 진행 중에는 나오지 않습니다.
4. 심사에는 `public/about.html`, `public/privacy.html`이 쓰입니다. **`privacy.html`의 문의 이메일(`contact@example.com`)을 실제 이메일로 바꾸세요.**

## 출시 전 점검

- 원작 보드게임의 이름, 로고, 카드 문구, 그림, 소리를 쓰지 않았는지 다시 확인합니다 (이 프로젝트는 규칙만 참고했습니다).
- `data/SOURCES.md`의 단어 목록 라이선스를 확인합니다. 한국어 목록은 CC BY-SA 4.0이라 `about.html`의 출처 표기를 지우면 안 됩니다.
- 이 문서는 법률 자문이 아닙니다.
